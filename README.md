# 🎬 Stream Vibe

A modern and responsive movie streaming platform UI built using React.js and Tailwind CSS. Stream Vibe provides users with an engaging experience to explore movies, TV shows, subscriptions, and entertainment content through a clean and intuitive interface.

---

## 📌 Project Overview

This project was developed to showcase frontend development skills using modern React practices and responsive design principles.

The application demonstrates:

* Scalable React application architecture
* Dynamic routing with React Router
* Reusable and maintainable components
* Responsive layouts across all devices
* Modern UI development with Tailwind CSS
* Clean folder structure and code organization

Stream Vibe delivers a premium streaming-platform experience inspired by modern OTT services.

---

## 🛠 Tech Stack

⚛️ React.js
🎨 Tailwind CSS v4
⚡ Vite
